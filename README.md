# nsb-handyman
Professional handyman service website

## Contents

- `prompts/MASTER_PROMPT.md` — New Smyrna Handyman LLC master AI assistant prompt (2026 estimates, invoices, pricing, and job management). PART 22 / MODE K cover the plat-agent integration.

After cloning, fetch the submodule with:

```bash
git submodule update --init
```
